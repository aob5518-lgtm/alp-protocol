# ALP testnet user guide

ALP is testnet-only software. Never send value to an address that is not published in the verified address book.

1. Switch your wallet to BSC Testnet (chain ID 97).
2. Open the application and verify the network badge says **BSC Testnet**.
3. Open an asset only after its address, oracle source and risk status are indexed from chain events.
4. Bind a sponsor only after reviewing it: binding is permanent.
5. Request an on-chain quote. It determines the 50% partner asset and 50% USDT split; do not rely on a frontend calculation.
6. Approve the exact required assets, then create a position and retain the transaction hash.

Rewards are competitive emissions based on effective compute. They are not fixed returns. A liquidity-cycle obligation can restrict ALP wallet transfers.
