# ALP 测试网用户指南

ALP 当前仅用于测试网。未出现在已验证地址簿中的地址，禁止转入任何资产。

1. 将钱包切换至 BSC Testnet（链 ID 97）。
2. 打开应用，确认网络标识为 **BSC Testnet**。
3. 仅在资产地址、预言机来源和风险状态已由链上事件索引后参与。
4. 绑定 Sponsor 前请核对地址；绑定永久不可更换。
5. 必须请求链上报价。报价决定 50% Partner Asset 与 50% USDT，不应依赖前端自行计算。
6. 按准确额度授权资产，创建 Position 后保存交易哈希。

ALP 收益是基于有效算力的竞争性 Emission，不是固定回报。流动性周期义务可能限制 ALP 钱包转账。
