# Security

ALP is BSC Testnet development software, not production-ready financial software. Contract access control is multisig/governance-oriented; the API uses SIWE signature verification, nonce replay protection, role checks, and immutable audit records.

No UI value is a substitute for a contract read. Do not fund an undeployed address or trust a missing address book. A mainnet release requires independent smart-contract audit, threat modelling, key ceremony, monitoring, incident runbook, and legal review.
